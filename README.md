# World model experimentation

This repository follows my progression towards understanding world models. The goal is summarized in the [project_statement](https://github.com/Bebel19/world-model-experimentation/blob/main/docs/project_statement.md).

## Docs

The docs folder contains a [glossary](https://github.com/Bebel19/world-model-experimentation/blob/main/docs/glossary.md) containing useful definitions to understand "Reactive World Models for Autonomous Driving". It also contains some papers in the [biblio folder](https://github.com/Bebel19/world-model-experimentation/tree/main/docs/biblio).
